# NTE ภาษาไทย Android 0.3.0

ติดตั้ง `NTE-Thai-Android-0.3.0.apk` ทับรุ่น 0.1.0/0.2.0 ได้โดยใช้ลายเซ็นเดิม **ไม่ต้องถอนแอปเก่า** เพื่อเก็บคลังฟอนต์และค่าที่เลือกไว้ รองรับ Android 11 ขึ้นไป arm64 / x86_64 รอให้งานแปลหรือคืนค่าเสร็จก่อนติดตั้งอัปเดต

1. ตั้งค่า Shizuku และอนุญาตให้แอปใช้งานตามคู่มือในแอป
2. ปิดเกม NTE ก่อนกดแปลหรือคืนค่า ตั้งภาษาข้อความในเกมเป็น English แล้วกดแปลเกม รอผลสำเร็จก่อนเปิดเกม
3. **ไม่ต้องคืนค่าทุกครั้งหลังเล่น** ปิดแอปแปลได้หลังติดตั้งสำเร็จ คำแปลยังอยู่ เปิดแอปใหม่จะตรวจไฟล์จริงเมื่อเชื่อมต่อ Shizuku ได้
4. **คืนค่าก่อนอัปเดตเกม** แล้วกดแปลใหม่หลังเกมดาวน์โหลดอัปเดตเสร็จ การอัปเดตแอปแปลอย่างเดียวไม่ต้องคืนค่าเกม ถ้าจะเลิกใช้หรือถอนแอปแปล ให้คืนค่าแพ็กก่อน เพราะถอน APK ไม่ได้ถอนแพ็กเกม

## ฟอนต์

เลือกภาษาไทยและ English แยกกันจากคลัง หรือเพิ่ม TTF ของตนเอง แล้วกลับไปกดแปลเกมเพื่อนำไปใช้ ฟอนต์ที่นำเข้าเก็บในเครื่อง ลบได้เฉพาะฟอนต์ที่เพิ่มเอง ฟอนต์เริ่มต้นของเกมและฟอนต์ที่มากับแอปเก็บไว้เสมอ เครดิตอยู่ที่ “ข้อมูลแอปและเครดิตฟอนต์” หน้าแหล่งฟอนต์เดิมถูกนำออกแล้ว

## อัปเดตในแอป

- รุ่น 0.3.0 เริ่มรองรับระบบอัปเดต จึงต้องติดตั้งรุ่นนี้ด้วย APK ครั้งแรกก่อน รุ่น 0.2.0 ไม่มีระบบดังกล่าว
- เมื่อเปิดหรือกลับเข้าแอป จะตรวจ GitHub เมื่อพ้น 6 ชั่วโมงจากการตรวจสำเร็จครั้งก่อน มีปุ่มตรวจเองได้ทันที ไม่มีการแจ้งเตือนเบื้องหลังขณะปิดแอป
- เมื่อพบ Release Android รุ่นใหม่ แอปแสดงข้อความและปุ่มดาวน์โหลด มีเปอร์เซ็นต์ตามจำนวนไบต์จริง ตรวจขนาด SHA-256 และลายเซ็น APK ตรงกับแอปเดิม รวมทั้งชื่อแพ็กเกจและรุ่นก่อนส่งให้ตัวติดตั้ง
- ดาวน์โหลดผ่าน Wi-Fi หรือเน็ตมือถือได้ ปริมาณข้อมูลประมาณขนาด APK ที่แสดง ให้เปิดแอปไว้จนเสร็จ หากปิดโปรเซสหรือเน็ตขาดให้กดลองใหม่ เริ่มดาวน์โหลดใหม่ ไม่รองรับดาวน์โหลดต่อบางส่วน
- ดาวน์โหลดเสร็จจะเปิดตัวติดตั้ง Android เมื่อแอปอยู่ด้านหน้าและไม่มีงานแปล/คืนค่าค้าง Android อาจขออนุญาต “ติดตั้งแอปจากแหล่งนี้” และผู้ใช้ต้องกดยืนยันติดตั้งเอง
- ถ้าผู้ใช้ยกเลิก สามารถกด “ติดตั้งอัปเดต” อีกครั้งในแอป ระบบไม่ติดตั้งเงียบ
- Release ของ Android แยกจาก Windows และมี Manifest กำกับไฟล์ จึงไม่เปลี่ยนรุ่นล่าสุดของตัวติดตั้ง PC ดูแนวทางเผยแพร่ใน [BUILD.md](https://github.com/Mojimini/NTE-Neverness-to-Everness-Thai-Translation/blob/main/BUILD.md)

Build, unit tests, lint, การดาวน์โหลดไฟล์ทดสอบ และการปฏิเสธลายเซ็น/ไฟล์เสียผ่าน คำแปลสามไฟล์เดิมครบ 110,260 รายการ ไม่เปลี่ยนข้อความหรือไฟล์หลัก PC

- [Windows EXE รุ่นล่าสุด](https://github.com/Mojimini/NTE-Neverness-to-Everness-Thai-Translation/releases/latest)

Android ใช้ stable Release `android-vX.Y.Z` พร้อม APK และ android-update.json เท่านั้น Windows ยังคงใช้ stable Latest Release `vX.Y.Z` กับ EXE

ผู้เผยแพร่ Android ต้องเลือก **ไม่ตั้งเป็น Latest** (`gh release create ... --latest=false`) เพื่อให้ตัวอัปเดต Windows เดิมยังทำงานได้ ไฟล์แนบใน Android Release ใช้ชื่อ ASCII เช่น GUIDE-ANDROID-TH.md เนื้อหาเขียนภาษาไทยได้

APK และ Manifest ต้องมาจากการสร้าง/ลงลายเซ็นครั้งเดียวกัน เพิ่ม versionCode ทุกครั้งและใช้กุญแจเดิม ห้ามแจก signing key หรือรหัสผ่าน
