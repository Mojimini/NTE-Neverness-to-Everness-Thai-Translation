# NTE ภาษาไทย — Neverness to Everness Thai Translation
เป็นม็อดภาษาไทยไม่เป็นทางการรสำหรับ Neverness to Everness (NTE)<br>
การแปลยึดตาม English เป็นหลัก

## กี่ยวกับโปรเจกต์
ทำขึ้นเพราะอยากอ่านเนื้อเรื่องแต่แปล English ไม่ได้เร็วเลยเกิดความขาดตอนตอนอ่านเนื้อเรื่องเลยเกิดเป็นโปรเจกต์แปลไทยนี้ขึ้นมา<br>
แนวทางการแปล เน้นรักษาความหมายของ English แต่ก็เรียบเรียงให้อ่านเข้าใจได้ด้วย<br>
แต่ยังมีบางส่วนที่อังกฤษยังขัดกันเองบางส่วนเลยถิอว่ายังไม่ 100% <br>
ตัวแปลนี้เป็นการ **แจกฟรี** ไม่ได้ทำมาขาย

## สถานะโปรเจกต์
- เวอร์ชั้นปัจจุบัน 1.4.5 
- คำแปลครบ 110,260 รายการแต่เหลือ 2,742 รายการ ที่อังกฤษขัดกันเองบางส่วนแต่ได้รับการแปลแล้ว
- รองรับ PC (Windows) และ Android 11 ขึ้นไปผ่าน Shizuku โดยแยกตัวติดตั้งและระบบอัปเดตกัน
- ยึดตาม English เป็นหลัก
- การอัwเดทขึ้นอยู่กับแพทแต่ละครั้งที่เกมอัwเดท

**[ดาวน์โหลดตัวติดตั้ง EXE รุ่นล่าสุด](https://github.com/Mojimini/NTE-Neverness-to-Everness-Thai-Translation/releases/latest)**

ดาวน์โหลดไฟล์ `Thai-Translator-Setup-….exe` จากหน้า Releases แล้วเปิดเพื่อติดตั้ง เลือกตำแหน่งลงโปรแกรมได้ ไม่ต้องดาวน์โหลด ZIP แพ็กเสริมเอง โปรแกรมจะดาวน์โหลดส่วนที่จำเป็น

## Android / มือถือ

**[ดาวน์โหลด APK Android 0.3.0](https://github.com/Mojimini/NTE-Neverness-to-Everness-Thai-Translation/releases/download/android-v0.3.0/NTE-Thai-Android-0.3.0.apk)** · [หน้า Release Android](https://github.com/Mojimini/NTE-Neverness-to-Everness-Thai-Translation/releases/tag/android-v0.3.0) · [คู่มือ Android](docs/ANDROID.md)

Android 11 ขึ้นไป (arm64 / x86_64) ใช้ Shizuku ที่เริ่มบริการและผู้ใช้อนุญาตแล้ว ตั้งภาษาในเกมเป็น English ปิดเกมก่อนกด **แปลเกม** หรือ **คืนค่า** ไม่ต้องคืนค่าหลังเล่นทุกครั้ง ให้คืนค่าก่อนอัปเดตเกมแล้วแปลใหม่หลังอัปเดตเสร็จ

มีคลังฟอนต์ไทย/English แยกกัน นำเข้า TTF ของตนเองได้ รุ่น 0.3.0 เพิ่มแจ้งอัปเดตและดาวน์โหลด APK ในแอป ตรวจไฟล์ก่อนเปิดตัวติดตั้ง Android ซึ่งผู้ใช้ต้องกดยืนยันเอง ผู้ใช้รุ่นเก่าต้องติดตั้ง APK 0.3.0 ครั้งแรกก่อนเพื่อเริ่มใช้ระบบอัปเดต

**มือถือและคอมอัปเดตแยกกัน**: Android อ่านเฉพาะแท็ก `android-vX.Y.Z` และไฟล์ APK ส่วน Windows ใช้แท็ก `vX.Y.Z` และตัวติดตั้ง EXE การออกอัปเดตแพลตฟอร์มหนึ่งไม่ติดตั้งอีกแพลตฟอร์มตามไปด้วย

รุ่นเกม Android ที่เคยทดสอบแพ็ก: App 1.4.0.88728 / Res 1.4.7.565814 ผู้ใช้แจ้งว่าฟอนต์แสดงในเกมได้แล้ว ยังไม่รับรองมือถือทุกรุ่นหรือทุกฉาก

## เริ่มใช้งานบนคอม (Windows)

1. ติดตั้งโปรแกรมและเลือกโฟลเดอร์เกม NTE

   <img width="450" height="450" alt="image" src="https://github.com/user-attachments/assets/5633f60d-e8ce-40c8-9dba-2caa69e61f0f" />

2. ตั้งภาษาในเกมเป็น **English** และปิดตัวเกมก่อนกด **แปลเกม**

   <img width="1750" height="120" alt="image" src="https://github.com/user-attachments/assets/dc2ce2be-3142-4cfc-9c67-734052444afc" />

3. กดแปลเกมในโปรแกรมให้ขึ้น 100% แล้วเข้าเกมได้เลย<br>
   3.1ตอนกดแปลโปรแกรมจะทำงานประมาณนี้
    - ตรวจความพร้อม — ตรวจตำแหน่งเกม ตัวเกมต้องปิดอยู่ แต่เปิด Launcher ค้างไว้ได้ และป้องกันการทำงานซ้อนกัน
    - เตรียมไฟล์คำแปล — ใช้ชุดไฟล์ที่แปลไว้แล้ว 110,260 รายการ หากไฟล์ขาดหรือเสียจะดาวน์โหลดจาก GitHub และตรวจไฟล์
    - เตรียมฟอนต์ที่เลือก — ฟอนต์เดิมใช้แพ็กสำเร็จรูป หากเลือกฟอนต์อื่น เช่น Monocraft จะสร้างแพ็กให้ตรงกับฟอนต์ไทยและอังกฤษที่เลือก
    - ตรวจไฟล์เกม — ตรวจว่าไฟล์ตรงกับรุ่นที่รองรับ และไม่มีไฟล์ชื่อชนก่อนติดตั้ง
    - เพิ่มไฟล์ลงเกม 6 ไฟล์ — แพ็กคำแปล 4 ไฟล์ และตัวโหลด 2 ไฟล์ พร้อมบันทึกข้อมูลสำหรับคืนค่า โดยเก็บไฟล์ต้นฉบับของเกมไว้
    - ตรวจไฟล์ที่ติดตั้งอีกครั้ง — เมื่อครบและถูกต้องจึงแสดงสถานะสีเขียวและ 100% พร้อมเปิดเกม

   <img width="450" height="450" alt="Animation" src="https://github.com/user-attachments/assets/52ff29a1-9a7f-4461-a467-67b0463efd49" />

5. ไม่ต้องคืนค่าทุกครั้งหลังเล่น ให้คืนค่าก่อนอัปเดตเกม แล้วกดแปลใหม่หลังอัปเดตเสร็จ

<img width="905" height="280" alt="image" src="https://github.com/user-attachments/assets/528db514-396a-4bbd-b6d4-55d985ad31ab" /> <br>

5. หากปิดโปรแกรมตอนแปลเสร็จแล้วเล่นได้ตามปกติเมื่อเปิดโปรแกรมไหม่โปรแกรมจะตรวจว่าได้ทำการแปลแล้วหรือยัง

## ฟอนต์และหน้าต่าง

- โหมดมืดเป็นค่าเริ่มต้น สลับมืด/สว่างได้
- เลือกฟอนต์ไทยและอังกฤษแยกกัน พร้อมตัวอย่างข้อความรวม
- สามารถนำเข้าฟอนต์เองได้ `.ttf` เก็บไว้ในคลัง เลือกใช้ภายหลังหรือลบได้ ฟอนต์เริ่มต้นล็อกเอาไว้
- แถมฟอนต์อังกฤษ **Monocraft** สไตล์ Minecraft มาให้ลอง
- แพ็กคำแปลและเครื่องมือสร้างฟอนต์ดาวน์โหลดเมื่อจำเป็น ใช้ไฟล์ที่ตรวจแล้วซ้ำได้

## อัปเดตโปรแกรม

เมื่อมีรุ่นใหม่ใน GitHub Releases โปรแกรมจะแสดงแถบแจ้งเตือนพร้อมปุ่ม **อัปเดต** และมีปุ่มตรวจหาอัปเดตในแท็บสถานะ ระบบดาวน์โหลดตัวติดตั้ง ตรวจขนาดและ SHA-256 แล้วติดตั้งกลับตำแหน่งเดิม โดยเก็บค่าตั้ง คลังฟอนต์ และข้อมูลคืนค่าเกมไว้

ถ้าอินเทอร์เน็ตไม่พร้อม โปรแกรมยังเปิดใช้งานไฟล์ที่ดาวน์โหลดแล้วและคืนค่าเกมได้ อัปเดตโปรแกรมไม่ได้ติดตั้งคำแปลชุดใหม่ลงเกมเอง หากแพ็กคำแปลเปลี่ยน ให้คืนค่าเดิมแล้วแปลเกมอีกครั้ง
