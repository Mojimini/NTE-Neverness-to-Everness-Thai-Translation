# NTE ภาษาไทย — ตัวติดตั้งและอัปเดต

โปรแกรมแปลภาษาไทยสำหรับ Neverness to Everness (NTE) รุ่นเกม 1.4.5 ใช้คำแปล v28c และหน้าต่างจาก UI6 ที่ปรับให้มีระบบดาวน์โหลดและอัปเดต

## ติดตั้งและเริ่มใช้

1. เปิดไฟล์ `Thai-Translator-Setup-1.0.0.exe` เลือกโฟลเดอร์ที่ต้องการ แล้วติดตั้ง
2. เปิดโปรแกรม NTE ภาษาไทย เลือกตำแหน่งเกม และตั้งภาษาในเกมเป็น English
3. ปิดตัวเกมก่อนกด **แปลเกม** เปิด Launcher ค้างไว้ได้ โปรแกรมดาวน์โหลดเฉพาะไฟล์ที่จำเป็นและตรวจสอบก่อนติดตั้ง
4. เมื่อสถานะสำเร็จแล้วจึงเปิดเกม หลังเลิกเล่นปิดโปรแกรมได้โดยคงคำแปลไว้ ไม่ต้องคืนค่าทุกครั้ง

ครั้งแรกที่แปลเกมจะดาวน์โหลดแพ็กคำแปล หากเพิ่มหรือใช้ฟอนต์ที่เลือกเองจะดาวน์โหลดเครื่องมือฟอนต์เพิ่ม อินเทอร์เน็ตขาดระหว่างดาวน์โหลดให้กดทำรายการใหม่ ไฟล์ที่ยังไม่ครบจะไม่ถูกนับว่าใช้ได้

## ฟอนต์และธีม

เลือกฟอนต์ไทยกับอังกฤษแยกกัน มีตัวอย่างรวมภาษาไทยและอังกฤษ ฟอนต์เดิมของเกมเป็นค่าเริ่มต้นและลบไม่ได้ เพิ่ม TTF ของตนเองไว้ในคลังและเลือกกลับมาใช้ได้ มี Monocraft สไตล์ Minecraft ให้เลือกสำหรับอังกฤษ

เมื่อคำแปลติดตั้งอยู่ ให้คืนค่าเดิมก่อนเปลี่ยนฟอนต์แล้วแปลอีกครั้ง โหมดมืดเป็นค่าเริ่มต้น สลับธีมมืด/สว่างได้จากปุ่มด้านบน

## อัปเดต

โปรแกรมตรวจรุ่นใหม่จาก GitHub Releases เมื่อเปิดและเป็นระยะ หากพบรุ่นใหม่จะมีข้อความพร้อมปุ่ม **อัปเดต** หรือกดตรวจเองจากแท็บสถานะได้

กดอัปเดตเพื่อดาวน์โหลดตัวติดตั้งที่ตรวจสอบแล้ว โปรแกรมจะปิดหน้าต่างติดตั้งอัปเดตและเปิดกลับมา ค่าตั้ง ฟอนต์ที่เพิ่มไว้และตำแหน่งเกมยังอยู่ หากดาวน์โหลดไม่สำเร็จสามารถลองใหม่ได้

อัปเดตโปรแกรมไม่ได้แปลเกมใหม่เอง หากรุ่นใหม่มีแพ็กคำแปลเปลี่ยน ให้คืนค่าชุดเดิมแล้วกดแปลเกมเพื่อนำชุดใหม่ไปใช้ ตรวจเลขรุ่นเกมที่รองรับก่อนอัปเดตเกม

## คืนค่าและถอนติดตั้ง

ใช้ **คืนค่าเดิม** เมื่อต้องการหยุดใช้คำแปล เปลี่ยนฟอนต์ หรือเตรียมอัปเดตเกม ก่อนถอนติดตั้งโปรแกรมต้องคืนค่าคำแปลในเกมก่อน คลังฟอนต์และค่าตั้งส่วนตัวเก็บแยกจากไฟล์โปรแกรม

การตรวจไฟล์และการติดตั้งครบไม่ได้รับรองการแสดงผลของทุกฟอนต์หรือความหมายทุกฉาก ฟอนต์ที่เลือกเองควรทดลองสัดส่วนและการตัดบรรทัดในเกม
